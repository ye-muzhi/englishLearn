## 已落地

1. 字幕侧栏只保留跟随和双语两个高频状态；搜索与列表字号收进按需工具层。
2. `Ctrl+F` / `Cmd+F` 直接聚焦字幕搜索，匹配原文与译文，Esc 清空并返回列表。
3. macOS 和 Windows 都有双击入口；首次运行自动创建隔离环境。
4. FFmpeg 在首次需要媒体处理时按平台准备，避免要求普通用户手动安装。
5. 发行脚本明确排除 `work/`、模型、媒体、字幕、密钥与本地环境。
6. Git 基线保护源码；用户数据不进入版本库。

## 下一阶段优先级

### P0：稳定和可诊断

- 任务中心：显示排队、处理中、失败、重试，不让失败信息只存在于瞬时提示。
- 一键导出诊断包：应用版本、依赖版本、失败阶段和脱敏日志。
- Windows/macOS CI：每次提交至少验证安装脚本、启动健康检查和发行包内容。

### P1：阅读效率

- 当前字幕轻量编辑：原文/译文并排修改、自动保存、撤销，时间轴不变。
- 搜索结果计数和上一个/下一个匹配；播放时搜索不打断视频。
- 内置快捷键帮助面板，只展示当前页面可用操作。

### P2：高级字幕工具

- 可选波形视图，用于专业级起止时间校准，不默认占据播放器。
- 项目导入/导出包，允许用户在两台电脑之间迁移学习数据。
- 可选 Anki 导出；不把第三方账号连接放到主观看流程。
